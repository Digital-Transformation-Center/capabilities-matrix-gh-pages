# Benchtop Collaborative Robot Arm

Compact 6-axis collaborative robot arm used in the DTC Model Shop for prototyping automated pick-and-place routines, testing custom 3D-printed end-effectors, and developing automated maintenance workflows.

## Features
- 6-degree-of-freedom articulated arm with torque feedback safety sensors for cage-free operation.
- Standardized tool flange interface supporting quick-change magnetic and pneumatic tool changers.
- Programmable digital/analog I/O and Ethernet interface for integrating grippers and sensors.
- Teach pendant and Python/ROS API support for rapid trajectory and motion sequence development.
