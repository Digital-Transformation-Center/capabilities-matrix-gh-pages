# PCB CNC Milling & Prototyping Station

High-precision desktop CNC milling machine used in the DTC Model Shop for rapid in-house prototyping of single- and double-sided printed circuit boards (PCBs), trace isolation milling, and hole drilling.

## Features
- Rapid isolation milling and contour routing for copper-clad laminates (FR-4, Rogers).
- Automatic tool change and high-speed spindle for micro-drilling through-holes and vias.
- Integrated height sensing for precise copper isolation depth without chemical etching.
- Supports Gerber and Excellon drill files generated by standard EDA packages (Altium, KiCad, Eagle).
