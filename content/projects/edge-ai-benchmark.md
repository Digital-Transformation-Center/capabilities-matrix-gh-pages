# Edge AI Model Benchmarking & Thermal Test Fixture

- **Physical:** An actively cooled, sensorized test rack holding multiple low-power edge compute modules, instrumented to monitor real-time current draw and thermal generation.
    
- **Digital/AI:** Displays live frame rates, watt-per-inference metrics, and latency across different optimized vision architectures (e.g., YOLO variants vs. quantized models).
    
- **Member Interest:** Algorithm optimization (MathWorks), edge hardware evaluation (IBM), defense venture acceleration (Sightline Ventures).
